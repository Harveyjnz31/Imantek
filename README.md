## 💻 Características Técnicas de la Web

El desarrollo se enfoca en la excelencia estética (Rich Aesthetics) y de rendimiento mediante:
*   **Acentos Visuales Magnéticos:** Uso de una paleta HSL oscura en fondo con acentos de brillo electromagnético (Cian para Polo Sur/Atracción y Rosa profundo para Polo Norte/Repulsión).
*   **Efecto Glassmorphism:** Tarjetas de cristal esmerilado con bordes degradados interactivos y difuminado de fondo (`backdrop-filter`).
*   **Simulador Magnético en Canvas:** Un laboratorio en tiempo real desarrollado en JavaScript que simula de manera físicamente precisa un campo de dipolo magnético. El usuario puede arrastrar el imán bipolar, ajustar la densidad e intensidad del campo magnético y ver líneas de fuerza y partículas (flujo de electrones) reaccionar de manera dinámica.
*   **SEO y Estructura:** Título semántico, metadescripción optimizada, jerarquía de encabezados HTML5 y diseño totalmente responsivo mediante Flexbox y CSS Grid.

## 🐙 Guía de Control de Versiones con Git y GitHub

El proyecto ya está preparado localmente con archivos de configuración para Git. Siga estos sencillos pasos en su consola para sincronizar este repositorio local con su cuenta personal de **GitHub**:

### 1. Inicialización de Git (Ya configurada y lista en tu entorno)
El proyecto ha sido inicializado localmente. Si desea verificar el estado de los archivos:
```bash
git status
```

### 2. Crear un Repositorio Nuevo en GitHub
1.  Inicie sesión en su cuenta de [GitHub](https://github.com).
2.  Haga clic en el botón **New** (Nuevo) para crear un repositorio.
3.  Escriba el nombre del repositorio: `Imantek`.
4.  Deje las opciones de inicialización vacías (es decir, **NO** active las casillas de agregar `README.md`, `.gitignore` o licencias, ya que el proyecto local ya cuenta con ellos en su versión óptima).
5.  Haga clic en **Create repository**.

### 3. Vincular y Subir el Proyecto
Copie y ejecute los siguientes comandos en la terminal (asegúrese de estar en el directorio de su proyecto):
```bash
# 1. Enlazar el repositorio local con el repositorio remoto de GitHub
# (Reemplace 'TuUsuario' con su nombre real de usuario de GitHub)
git remote add origin https://github.com/TuUsuario/Imantek.git

# 2. Renombrar la rama a 'main'
git branch -M main

# 3. Subir el proyecto a GitHub
git push -u origin main
```

¡Listo! A partir de este momento, cualquier cambio que realice podrá ser guardado en la nube con:
```bash
git add .
git commit -m "Descripción corta de los cambios realizados"
git push
```
